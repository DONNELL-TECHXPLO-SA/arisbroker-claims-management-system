# Deployment

How the system gets built, released, and run in each environment.

- `deployment-process.md` — step-by-step or CI/CD pipeline description

- `rollback.md` — how to revert a bad release
- `secrets-management.md` — how credentials/secrets are stored and rotated (never commit real secrets here)
