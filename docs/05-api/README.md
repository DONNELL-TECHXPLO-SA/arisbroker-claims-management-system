# API Documentation

- `endpoints.md` — REST/GraphQL endpoint reference (method, path, params, responses)
- `auth.md` — authentication & authorization flow (tokens, roles, permissions)
- `error-codes.md` — standardized error responses
- `openapi.yaml` (optional) — machine-readable spec if using OpenAPI/Swagger
